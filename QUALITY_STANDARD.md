# Unified Repository Quality Standard

This monorepo is a provenance-preserving integration workspace. Structural import is not runtime compatibility. Canonical labels: **Implemented**, **Prototype**, **Designed**, **Historical**, **Verified**, and **Unverified**.

Every promoted component requires boundary, dependency, license, test, and evidence review. Preserve source snapshots and provenance. Do not publish private material or secrets without an explicit authorization decision.
