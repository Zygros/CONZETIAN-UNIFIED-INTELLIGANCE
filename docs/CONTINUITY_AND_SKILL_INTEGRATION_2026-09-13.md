## Evidence model

Every imported skill, repository, paper, model, dataset, or external tool should be assigned:

`L0 concept`
`L1 specification`
`L2 artifact`
`L3 cryptographic identity`
`L4 executable implementation`
`L5 reproducible tests`
`L6 benchmark`
`L7 independent verification`

No source receives a higher level merely because an AI endorsed it.

## Integration principle

The skill lattice, repository federation, external ecosystem, and HTC should not be four separate projects. They are four views of one lifecycle:

```text
SKILLS define HOW
REPOSITORIES contain WHAT
ECOSYSTEM provides NEW CANDIDATES
HTC determines WHAT SURVIVES
OMEGA-10 records WHAT WAS PROVEN
CONZETIAN-AI decides HOW TO COMPOSE IT
CONZETIAN-UNIFIED preserves THE MAP
SOVEREIGN-FEDERATION exposes THE GRAPH
```

## Preservation rule
